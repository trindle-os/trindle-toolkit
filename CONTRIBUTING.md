# Contributing

Thank you for taking an interest in the Trindle Toolkit. It is appreciated.

The way this project is set up, the code is written and kept in one place by one maintainer, so changes to the code are not taken from outside. That has nothing to do with the quality of anyone's work. It works best when the maintainer hears what went wrong and fixes it in step with the programs that use the toolkit.

So the most useful thing you can send is a description:

- **Something broken?** Tell us what you did, what you expected and what happened instead. Say which version you run, which compositor and desktop, and your Rust version. A picture or the program's output helps a great deal.
- **An idea?** Tell us what you were trying to build and where the toolkit got in the way. You do not need to suggest the fix.
- **A security problem?** Please use private reporting rather than a public report. [SECURITY.md](SECURITY.md) explains how.

Report bugs and ask questions on the [Buildmorphic community](https://buildmorphic.com).

The toolkit is GPL-3.0-or-later, so you are always free to fork it and take it in your own direction.
